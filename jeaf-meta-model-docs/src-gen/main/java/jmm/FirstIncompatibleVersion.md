# Stereotype `«FirstIncompatibleVersion»`
The `«FirstIncompatibleVersion»` stereotype is used to indicate the first version that is incompatible with the source version.

This stereotype can only be applied to a dependency between two `«CompatibilityInfo»` elements.

<br>

| **Stereotype**          | `«FirstIncompatibleVersion»` | |
| ----------------------- | -------------- | |
| **Applicable Elements** | `Dependency`        |
| **Tagged Values**       | `none`           |
