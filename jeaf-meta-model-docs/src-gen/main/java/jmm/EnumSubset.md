# Stereotype `«EnumSubset»`
The `«EnumSubset»` stereotype can be used to further restrict the valid values of an enum property.

This can be achieved either by defining an explicit list of allowed literals via `allowedLiterals` or by specifying literals that are not permitted via `notAllowedLiterals`. Only one of these options may be used at a time; they cannot be used simultaneously.
