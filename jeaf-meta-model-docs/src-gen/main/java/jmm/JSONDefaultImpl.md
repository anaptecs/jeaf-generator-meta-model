# Stereotype `«JSONDefaultImpl»`
Stereotype `«JSONDefaultImpl»` can be used to designate a class within a class hierarchy as the default implementation.

This information is only relevant during Jackson deserialization when no explicit type mapping is available for the detected type. A typical scenario is when the client and server use different versions of the same API and a new class has been introduced into an existing class hierarchy. In such cases, the class marked with `«JSONDefaultImpl»` is used as the fallback implementation.

Please note that in situations where no meaningful default implementation exists, unknown subtypes can alternatively be ignored. This can be configured by setting the `ignoreUnknownSubtypes` tag of the `«POJO»` stereotype or globally through the JEAF Generator Maven Plugin configuration. This is particularly useful when newly introduced subtypes are not relevant for older clients and can be safely ignored during deserialization.
