# Stereotype `«HeaderParam»`
Stereotype `«HeaderParam»` is used to mark that a parameter of a REST operation should be taken from the http header. 

The stereotype can be applied to parameters of REST operations and to properties of a class that is marked as `«BeanParam»`.

<br>

| **Stereotype**          | `«HeaderParam»` | |
| ----------------------- | -------------- | |
| **Applicable Elements** | `Parameter` `Property`        |
| **Tagged Values**       |                       |                                                                                                                                                                                                          |
| **Name**                | **Type**              | **Description**                                                                                                                                                                                          |
| `value`   | `String` | Name of the HTTP header field from which the parameter value should be taken. If no name is defined then the name of the property / parameter will be used. |
| `technicalHeader`   | `Boolean` | If a header field is marked as a technical header then it will be part of the published API e.g. in the OpenAPI specification. However it will be hidden to the generated business code. |
